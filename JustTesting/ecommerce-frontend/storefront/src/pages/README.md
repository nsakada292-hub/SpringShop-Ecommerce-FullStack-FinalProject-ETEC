# pages/

One folder per route. Each folder owns its page component and any
sub-components used only on that page.

- `Home/`             Landing page: hero, featured products, reviews, footer
- `CategoryListing/`  Women / Men / Kid / Beauty listing pages + filter sidebar
- `ProductDetail/`    Single product page + "related products" section
- `Auth/`             SignIn, Register, VerifyOtp, ForgotPassword, ResetPassword
- `Cart/`             Full bag page (drawer lives in components/cart)
- `Wishlist/`         Full love-list page (drawer lives in components/wishlist)
- `NotFound/`         404 page
